# Inventory — what is in this packet, and what is not

This file exists so that nothing is withheld silently. Every exclusion below is either
third-party data the project's own policy forbids redistributing, build machinery, or a large
binary intermediate that a reviewer cannot read. The regeneration command for each is given.

## Included

| Item | Note |
|---|---|
| `01-PROJECT/` | The repository minus the exclusions below: source, tests, docs, configs, CI, scripts, `README.md`, `AGENTS.md`, `MEMORY.md`, `LICENSE`, `pyproject.toml`, `uv.lock` |
| `01-PROJECT/data/fixtures/` | Small synthetic and committed fixtures (CTU-13 header fixture, IoT-23 Zeek fixture, synthetic event JSON) |
| `01-PROJECT/data/evaluation/**/*.json` | **Readable result evidence** — held-out, stability, model-family, uncertainty, hardening, causal-overlap, reviewer-simulation, analyst-replay, unknown-workload summaries |
| `01-PROJECT/data/processed/*/dataset_manifest.json`, `quality_report.json` | Ingestion manifests and quality reports (no addresses) |
| `02-GOVERNANCE/github-issues.md` | All 44 issues with full bodies **and** comments — the problem → cause → attempts → failures → solution → change → proof chain |
| `02-GOVERNANCE/traces/` | 38 redacted local agent trace files |
| `02-GOVERNANCE/git-history.txt` | Full commit history with messages and per-commit file stats |
| `02-GOVERNANCE/issue-notes/` | Working notes, issue drafts, plans and attachments kept alongside the traces |
| `03-RESEARCH-INPUTS/` | The landscape scan plus the sources examined for it |
| `04-AUDIT-SCRIPTS/` | Adversarial audit probes written against the project's own claims |

## Excluded

| Excluded | Size | Reason | How to regenerate |
|---|---|---|---|
| `data/raw/` | 2.0G | Third-party CTU-13 raw captures. Project policy: *"Link to official sources instead of republishing third-party raw files."* | Download from the official Stratosphere IPS source; see `01-PROJECT/docs/datasets.md` |
| `data/**/*.parquet` | 777M | Derived feature tables and IP-bearing event tables. Large binaries a reviewer cannot read; the event tables also carry network addresses, which policy forbids exposing. | `uv run python scripts/ingest_ctu13.py ...` then the Phase 3 evaluation scripts; see `01-PROJECT/docs/methodology.md` |
| `data/evaluation/phase3_model_stability/stability_summary.json` | 133M | Per-row dump too large to read; the reviewed metrics are in `docs/phase3_model_stability.md` | Re-run the stability study |
| `data/evaluation/phase3_causal_representation/causal_summary.json` |  62M | Per-row dump too large to read; the reviewed metrics are in `docs/phase3_causal_representation.md` | Re-run the causal-representation study |
| `.venv/` | 425M | Local virtual environment | `uv sync --all-groups` |
| `.mypy_cache/`, `.pytest_cache/`, `.ruff_cache/`, `__pycache__/` |  21M (mypy) | Tool caches | Regenerated by running the tools |
| `.coverage` | 332K | Coverage database | `uv run pytest` |
| `.context/tmp_slice.binetflow` | 2.6M | Scratch slice used during development | Not needed |
| `.git/` | — | `kathmandu/` is a git *worktree*; its `.git` is a pointer, not a self-contained history. The history is preserved readably in `02-GOVERNANCE/git-history.txt` | — |

## Reproducing the gate

```bash
cd 01-PROJECT
uv sync --all-groups
uv run pytest          # 600 passed, 96.00% coverage
uv run ruff check .    # clean
uv run mypy            # clean, 54 source files
```

Six governance validators additionally run in CI (`.github/workflows/ci.yml`):
`validate_agent_trace.py`, `validate_experiment_registry.py`, `validate_phase3_evidence.py`,
`validate_preregistration.py`, `validate_results_ledger.py`, `validate_solution_knowledge.py`.

## Integrity

`MANIFEST.sha256` lists a SHA-256 digest for every file in this packet.
Verify with `shasum -a 256 -c MANIFEST.sha256` from the packet root.
